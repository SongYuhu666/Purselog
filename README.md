## 快速开始

### 本地运行
直接在浏览器中打开 `index.html` 即可使用，或使用本地服务器：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server
```

### 使用说明
1. 点击"记一笔"按钮
2. 选择收入/支出类型
3. 输入金额、备注（可选）、日期
4. 点击"保存"即可
5. 如需删除记录，点击记录右侧的"删除"按钮并确认
6. 如需清空所有记录，点击"清空所有数据"按钮并确认
7. 所有数据会自动保存到浏览器，刷新页面后不会丢失
