# Purselog - 极简记账

一个简洁优雅的纯前端记账应用，专注于提供最核心的记账功能。

## 版本历史

### [V1.0.0] - 2026-06-02

#### 核心功能
- ✅ 基础记账功能
- ✅ 收入/支出类型选择
- ✅ 金额输入（支持小数）
- ✅ 备注输入（可选）
- ✅ 日期选择（默认今天）
- ✅ 记录列表展示

#### 技术实现
- 纯 HTML + CSS + JavaScript（无第三方库）
- 使用蓝色为主色调 (#2563eb)
- 响应式设计，适配桌面端和移动端
- 代码结构清晰，带有详细注释

#### 文件变更
- `index.html` - 完整的记账应用代码

## 开发规范

### 版本管理原则
- 每个版本只实现一个核心功能
- 确保代码质量和可维护性
- 在提交前充分测试

### 版本命名规则
- `V{MAJOR}.{MINOR}.{PATCH}`
- MAJOR: 大版本更新（重大架构变更）

## 快速开始

### 本地运行
直接在浏览器中打开 `index.html` 即可使用，或使用本地服务器：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server
```

### 使用说明
1. 点击"记一笔"按钮
2. 选择收入/支出类型
3. 输入金额、备注（可选）、日期
4. 点击"保存"即可
