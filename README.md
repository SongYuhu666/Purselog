## 快速开始

### 本地运行
直接在浏览器中打开 `index.html` 即可使用，或使用本地服务器：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server
```

### 使用说明
1. 点击顶部标签页切换"概览"、"账单"和"分类管理"视图
2. 在"概览"页面查看统计卡片、图表和预算使用情况
3. 在"账单"页面点击"记一笔"添加新记录
4. 选择收入/支出类型
5. 选择对应的分类（可自定义）
6. 输入金额、备注（可选）、日期
7. 点击"保存"即可
8. 如需删除记录，点击记录右侧的"删除"按钮并确认
9. 如需清空所有记录，点击"清空所有数据"按钮并确认
10. 所有数据会自动保存到浏览器，刷新页面后不会丢失
11. 在"概览"页面查看本月支出分类饼图
12. 在"概览"页面查看近7天收支趋势折线图
13. 在"分类管理"页面管理收支分类
14. 支持添加、编辑、删除自定义分类
15. 每个分类可选择不同的图标和颜色
16. 在"概览"页面设置每个分类的月度预算
17. 进度条显示预算使用情况，超出80%为黄色警告，超支为红色
