# Purselog

极简记账应用 - 轻量、快速、美观，纯 HTML + CSS + JavaScript 实现

## 项目介绍

Purselog 是一款简单易用的个人记账应用，旨在帮助用户轻松记录收入和支出。

**设计理念：**
- 极简：界面简洁，功能聚焦
- 现代：蓝色为主色调，优雅的 UI 设计
- 轻量：无需安装任何依赖，直接在浏览器中使用

## 版本历史

### v1.0.0 - 2026-06-02

**核心功能**
- ✅ 基础记账功能
- ✅ "记一笔" 按钮和弹出表单
- ✅ 类型选择（收入/支出）
- ✅ 金额输入（数字类型，带 ¥ 符号）
- ✅ 备注输入（可选）
- ✅ 日期选择器（默认今天）
- ✅ 记录列表展示
- ✅ 保存成功提示（Toast）
- ✅ 响应式设计（适配桌面和移动端）

**技术实现**
- 纯 HTML + CSS + JavaScript，无第三方库依赖
- 使用语义化的 CSS 变量管理颜色
- 美观的卡片式设计
- 流畅的动画和过渡效果

**文件变更**
- 新增 `index.html` - 主页面和所有功能实现

## 使用说明

1. 下载或克隆本项目
2. 直接在浏览器中打开 `index.html` 文件即可使用
3. 点击 "记一笔" 添加新的收支记录

## 开发规范

### 版本管理原则
- 每个版本只实现一个核心功能
- 使用语义化版本号（MAJOR.MINOR.PATCH）
- 详细记录每个版本的变更

### 分支策略
- `main` - 主分支，保持稳定
- 功能开发在单独分支进行，完成后合并到 main 并打标签
